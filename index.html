Conectar con Google Sheets

Pega la URL de tu Apps Script Web App para que el dashboard lea los datos en tiempo real. Solo necesitas hacer esto una vez.

Paso 1 · Crea la estructura en Google Sheets En el editor Apps Script → ejecuta la función crearEstructuraInicial()
Paso 2 · Implementa como App Web Implementar → Nueva implementación → App web · Ejecutar como: Yo · Acceso: Cualquiera
Paso 3 · Pega la URL aquí La URL tiene este formato: https://script.google.com/macros/s/.../exec
